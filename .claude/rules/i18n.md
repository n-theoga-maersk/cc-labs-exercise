# Internationalisation

- Locales: `en`, `ja`, `pt_BR` (`client/src/locales/`). Any new UI string goes into **all three** files. `t('a.b')` falls back to English, then to the raw key.
- The locale is saved in `localStorage` as `app-locale`; the default comes from the browser language.
- API amounts are always USD. The display currency follows the locale (en → USD, ja → JPY, pt_BR → BRL), with no separate setting (ADR-0006). `currency.js` only converts JPY, at a fixed rate of 150, so **BRL currently renders as USD**. Format money with `formatCurrency` / `formatCurrencyWithDecimals` from `client/src/utils/currency.js`, using `currentCurrency` from `useI18n`. Never hard-code `$` or `toLocaleString('en-US', ...)` outside `currency.js`.
- Product and warehouse names from the API are English. Show them via `translateProductName` / `translateWarehouse`.
