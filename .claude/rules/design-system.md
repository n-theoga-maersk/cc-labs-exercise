# Design system

- Palette: slate/gray (`#0f172a`, `#64748b`, `#e2e8f0`). Status colours: green / blue / yellow / red.
- Charts are hand-written SVG (no chart library), and layouts use CSS Grid.
- Global styles live in `client/src/App.vue`; component styles are `scoped`.
- No emojis in the UI.
